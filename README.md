Dodatek **GPK Szemud - faktury za wodę**: czyta faktury PDF z Gmaila (IMAP), wystawia sensory przez MQTT

Instalacja: Ustawienia → Dodatki → Sklep → ⋮ → Repozytoria → wklej `https://github.com/VoyteckPL/ha-gpk-water`.
